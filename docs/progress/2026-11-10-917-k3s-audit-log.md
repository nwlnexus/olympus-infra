## Decisions

- 2026-11-10: Policy order (first match wins): drop health URLs; log everything by the agent read identities at Metadata; drop node, control-plane, lease and event noise; Metadata for Secrets, ConfigMaps, token reviews and token requests (never bodies); drop other ServiceAccount reads; Request for other writes; Metadata for the rest. Why: agent reads must always be recorded, Secret access must be visible without content, and controller watch noise would swamp the log.
- 2026-11-10: The play stages files and never restarts k3s. Why: a restart of the control plane is run by the owner, one server at a time, with the health gate.
- 2026-11-10: The policy file and log directory are created before the config block is written, and the play asserts both exist. Why: the API server does not start if the policy file is missing.
